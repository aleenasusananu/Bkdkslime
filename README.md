## GETTING STARTED

### Dependencies

You'll only need:

- A web browser (Google Chrome, Firefox, Microsoft Edge, etc.).
- A code editor if you want to view or edit the code (I used GitHub Codespaces).

No additional installations or libraries are required to view the website!

### Installing

1. Go to my GitHub repository.
2. Click on the green **Code** button.
3. Download the project as a ZIP file or clone the repository.
4. If you downloaded the ZIP file, extract it to a folder on your computer.

### EXECUTING THE PROGRAM

1. Open the project folder.
2. Find the `index.html` file.
3. Open it in your web browser.
4. That's it!! My portfolio website should now be up and running \:D

## HELP

If the website isn't displaying properly, here are a few things to check:

- Make sure you've downloaded all the project files.
- Check that `index.html` is in the correct folder.
- Make sure you're opening the correct HTML file.
- Check that any images or other linked files are in their original locations.

If you're still having trouble, try opening the project in another browser!
